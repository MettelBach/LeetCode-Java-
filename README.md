# SellHub — система управления продажами (аналог BaseLinker)

SaaS-панель для интернет-продавцов: заказы со всех маркетплейсов в одном месте, склад, офферы, отправки, счета, возвраты и автоматизация. Дизайн и логика повторяют BaseLinker (base.com). Интеграции: **Allegro, Empik Marketplace, Kaufland**.

> Название «SellHub» и логотип — свои (чтобы не нарушать товарный знак BaseLinker). Сменить можно в `web/src/brand.ts` и `web/public/favicon.svg`.

## Возможности

**Заказы** — колонка статусов с группами и счётчиками, список как в BaseLinker (номер, покупатель + источник, товары, оплата, статус, способ доставки, иконки оплаты/отправки/счёта, даты), расширенный поиск по 18 критериям, массовые действия (статусы, письма, счета/чеки, печать, отправки, объединение, архив, корзина, автоматические действия, экспорт CSV), карточка заказа (товары, оплата, статус, адреса, пункт выдачи, отправки, документы, возвраты, история), ручное добавление, разделение и дублирование заказов, публичная страница заказа для покупателя.

**Склад** — несколько каталогов и складов, остатки по складам, варианты товаров, категории и производители, импорт/экспорт CSV, история остатков, складские документы PZ / PW / WZ / RW / MM.

**Управление офферами** — загрузка офферов с маркетплейсов, автосвязка с товарами по SKU/EAN, выставление товаров со склада на Allegro/Empik/Kaufland, завершение и активация, массовое изменение цен, синхронизация остатков и цен.

**Интеграции** — каталог интеграций, реальные API: Allegro REST (OAuth device flow), Empik (Mirakl OR11/OR21/OR23/OR24/OF21/OF24), Kaufland Seller API v2 (подпись HMAC). Для каждой есть демо-режим без ключей. Маппинг статусов, автоматическая передача трек-номеров, автоприём заказов Empik.

**Akceleracje** — платное ускорение синхронизации остатков, цен, загрузки заказов и лимита API с посуточной оплатой.

**REST API** (`/api/v1`) — токены в «Настройки → API» (заголовок `X-Api-Token`), заказы (список, инкрементально по `id_from`, создание, статус, оплата), статусы, товары с остатками по складам, массовое обновление остатков и цен. Лимит запросов в минуту — из акселерации «API» (100/300/500).

**Отправки** — создание отправок (InPost, DPD, DHL, GLS, UPS, Pocztex, ORLEN, Allegro, FedEx), этикетки 10×15 со штрихкодом Code 128, протокол передачи курьеру, статусы отправлений.

**Счета** — счета-фактуры, проформы, чеки, корректировки, серии нумерации, PDF с польскими реквизитами.

**Возвраты** — статусы возвратов, возврат на склад, протокол возврата.

**Автоматические действия** — событие → условия → действия (смена статуса, письмо, счёт, чек, отправка, заметка, доп. поле, архив, webhook).

**SaaS** — регистрация с пробным периодом, тарифы и лимиты, подписка и баланс, пользователи аккаунта с ролями, сброс пароля, отдельная БД на каждого клиента.

**Помощь и контакты** — база знаний, обращения в поддержку с перепиской.

**Панель поддержки** (`/admin`) — обзор платформы (аккаунты, MRR, тикеты), список и карточка клиента (статистика, интеграции, ошибки синхронизации, тариф, статус, оплаты, источник привлечения — UTM/gclid/fbclid), выгрузка оплат для импорта офлайн-конверсий в Google Ads, вход в аккаунт клиента (с причиной, сеанс 2 часа, журнал аудита), очередь обращений (взять, ответить, внутренние заметки, статусы, приоритеты), команда, журнал аудита.

**Языки** — польский, английский, русский.

## Быстрый старт (Docker)

```bash
cp .env.example .env
# заполните JWT_SECRET (openssl rand -hex 32), ADMIN_EMAIL, ADMIN_PASSWORD, APP_URL, SMTP_*
docker compose up -d --build
```

Панель: `http://localhost:3001` → «Создать аккаунт» (можно с демо-данными).
Панель поддержки: `http://localhost:3001/admin` (логин из `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

Данные хранятся в томе `sellhub-data` (`/data`): `platform.db` и `tenants/<id>.db`. Бэкап — копия этой папки (или `sqlite3 ... .backup`).

## Разработка

```bash
npm run install:all
npm run dev:server   # API на :3001 (tsx watch)
npm run dev:web      # фронтенд на :5173 (проксирует /api)
npm test             # тесты API и коннекторов (vitest)
npm run i18n:check   # проверка переводов
npm run build && npm start   # прод-сборка
```

Демо-аккаунт из командной строки: `npm --prefix server run seed -- demo@example.com secret123 "Demo Sklep"`.

## Подключение маркетплейсов

| Маркетплейс | Что нужно | Где взять |
|---|---|---|
| Allegro | Client ID + Client Secret, затем «Авторизовать» | apps.developer.allegro.pl (тип приложения «device») |
| Empik | API key | Кабинет продавца Empik → настройки пользователя → API key |
| Kaufland | Client Key + Secret Key | Kaufland Seller Portal → Settings → API |

## Архитектура

- `server/` — Node 22, Express 5, TypeScript, better-sqlite3.
  - `src/db/` — схемы платформы и клиента, миграции, `db` — прокси на БД текущего клиента (AsyncLocalStorage).
  - `src/services/` — заказы, склад, счета, PDF, отправки, возвраты, письма, автоматизация, платформа (тарифы, акселерации, биллинг).
  - `src/integrations/` — коннекторы Allegro / Empik / Kaufland / демо, синхронизация и планировщик (каждую минуту, интервалы из акселераций).
  - `src/routes/` — REST API (`/api/*`, `/api/admin/*`, `/api/public/*`).
- `web/` — React 19, Vite, TanStack Query, React Router, Recharts; стили повторяют BaseLinker (`src/styles.css`).
- `docs/` — `TASKS.md` (все задания), `PROGRESS.md` (журнал), `MARKETING_PLAN.md` (план рекламы).

## Безопасность

Пароли — bcrypt; JWT с версией токена (выход на всех устройствах, блокировка пользователей); ограничение попыток входа; отдельная БД на клиента; секреты интеграций не отдаются во фронтенд; исходящие запросы только на публичные адреса (адрес API Empik — только домены Empik/Mirakl, SMTP клиента и webhooks — только публичные хосты, без редиректов); смена пароля завершает другие сессии; вход поддержки только с причиной и аудитом; экспорт CSV защищён от формул; заголовки `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`. В проде обязателен `JWT_SECRET` ≥ 32 символов и HTTPS (обратный прокси, например Caddy или Nginx).

## Перед запуском в прод

1. Заполнить `.env`, поднять за HTTPS-прокси, настроить ежедневный бэкап `/data`.
2. Проверить юристом шаблоны `Регламента` и `Политики конфиденциальности` (`web/src/pages/Legal.tsx`), заключить договор поручения обработки данных (RODO).
3. Настроить SMTP платформы (письма о регистрации, сбросе пароля, ответах поддержки).
4. Зарегистрировать приложения Allegro/Kaufland/Empik под своей компанией.
